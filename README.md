# Model

Het staat model voor digitale tuintjes welke bij 'Het web is voor iedereen' door studenten worden gemaakt.

## Learning Log

### MA 31 aug - Kickoff

-> Een fork van de model repository gemaakt en gepubliceerd via mijn eigen Github omgeving.
-> Alle stappen doorlopen om aan de lag te kunnen met de Digital Garden; Domeinnaam, Github, VSCodium en dit ook allemaal koppelen aan elkaar.

-> Checkout:

- Leg uit wat een source hosting platform is en voor welke jij gekozen hebt.

* Een source hosting platform is een platform/provider waar je als ‘gast’ jouw website vanaf kunt publiceren op het internet.
* Hierin schrijf/bewerk je de code, daarna wordt deze verstuurd naar

- Vertel welke domeinnaam jij gekozen hebt en hoe je die hebt gekoppeld aan jouw pagina.

* T-kiela, deze naam heb ik geregistreerd bij TransIP. (TransIP = de partij die internet registratie voor jou regelt)
* Kale domeinnaam koppelen aan de servers van Github. (DNS = verwijst naar source hosting platform, Github dus)
* CNAME record toevoegen aan DNS (CNAME = koppelt ene domeinnaam aan andere/echte domeinnaam)
* Domeinnaam ook op Github invoeren.

- Beschrijf hoe je aanpassingen aan jouw pagina kunt maken en hoe je er voor zorgt dat die op het web gepubliceerd worden.

* Door je code aan te passen in VSCodium en vervolgens op te slaan, je website wordt dan geüpdate.
